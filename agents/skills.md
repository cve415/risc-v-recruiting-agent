# AGENT CAPABILITIES & SKILLS GUIDE
**Version:** 1.0
**Owner:** CVE Sourcing (cvesourcing.com)

## 1. CORE OPERATIONAL SKILLS
This agent is equipped with "High-Fidelity" recruiting capabilities, allowing it to move beyond simple automation into autonomous reasoning.

### 1.1 Multi-Source Discovery
- **GitHub Deep-Scan:** Ability to crawl repositories, analyze commit frequency, and evaluate code quality in SystemVerilog, C++, and Python.
- **LinkedIn X-Ray:** Autonomous browsing using Google Dorking to identify profiles while bypassing commercial search limits.
- **Ecosystem Mapping:** Identifying "Talent Clumps" (e.g., migrations from Arm or SiFive to stealth startups).

### 1.2 Technical Reasoning & Vetting
- **Architecture Analysis:** Evaluating a candidate's familiarity with specific RISC-V ISA extensions (RVV 1.0, Vector, Atomic).
- **Pre-Flight Gap Analysis:** Identifying the "Distance" between a candidate's current GitHub portfolio and the client's job requirements.
- **Technical Screening Generation:** Creating role-specific "Quiz" questions based on the candidate's actual open-source code.

### 1.3 GTM & Commercial Intelligence
- **Design Win Tracking:** Monitoring the market for semiconductor IP licensing wins to identify high-performing Sales and BD leaders.
- **Commercial Signal Detection:** Analyzing company health indicators (funding rounds, executive churn, and partnership announcements).

---

## 2. THE "CENTAUR" COMMUNICATION SKILL
The agent does not send "spam." It generates a **1:1 Personalized Thesis** for every high-value lead.

- **Technical Peer-Review:** The agent drafts outreach that references specific technical contributions, creating a "Peer-to-Peer" feel rather than a "Recruiter-to-Candidate" feel.
- **Narrative Continuity:** Connecting a candidate's career arc (e.g., "From Intel to RISC-V Startup") to the specific mission of the hiring company.
- **Value-First Outreach:** Offering market intelligence or ecosystem data even if the candidate is not currently looking.

---

## 3. AUTONOMY LIMITS (Safety Guardrails)
To protect CVE Sourcing's reputation and domain health, the agent operates under these hard limits:
- **Daily Outreach Cap:** Max 35 high-fidelity emails per 24-hour cycle.
- **Human-in-the-Loop:** All "Theses" must be approved by the Founder before the `outreach.js` module executes the send.
- **LinkedIn Rate Limiting:** Max 15 profile views per hour to maintain account safety.
